# Innonsh Technologies App

This project is a React (Vite) and Node.js application built for Innonsh Technologies.

## Structure
- `/client`: Frontend React application using Vite, TailwindCSS, and GSAP.
- `/server`: Backend Node.js Express server.

## Getting Started

First, install dependencies for both client and server from the root directory:
```bash
npm install
npm run dev
```

This will concurrently start:
- Frontend: `http://localhost:5173`
- Backend: `http://localhost:5000`

## Build
To create a production build for the frontend, run:
```bash
npm run build
```
